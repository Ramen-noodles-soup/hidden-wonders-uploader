Hidden Wonders Uploader

A private desktop tool that uploads finished Hidden Wonders documentary videos (history, places and famous engineering mistakes) to the channel’s own YouTube account, using the YouTube Data API.

What it does

  1. The channel owner signs in once with Google (OAuth 2.0) and grants permission to upload to their own channel.
  2. For each finished video, the tool uploads the file with its title, description, tags, captions and thumbnail, as private.
  3. After the owner reviews and approves the week’s videos, the tool sets each video’s scheduled publish time.
  4. Once a video is public, the tool can post the owner’s first comment on it.

Who can use it

Only the owner of the Hidden Wonders channel. The tool is not offered, sold or distributed to anyone else, and it does not access any other user’s data.
