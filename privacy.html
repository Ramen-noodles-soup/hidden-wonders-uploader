Privacy Policy

Last updated: October 23, 2026

Hidden Wonders Uploader (“the tool”) is a private desktop application that uploads videos made for the YouTube channel Hidden Wonders (@Hiddenwonders-world) to that channel. The channel owner is its only user. It is not offered, sold or distributed to anyone else.

YouTube API Services

The tool uses YouTube API Services (the YouTube Data API v3). By using the tool, users are agreeing to be bound by the YouTube Terms of Service. YouTube API Services are provided by Google; see the Google Privacy Policy at https://policies.google.com/privacy.

What the tool accesses

  • Through Google sign-in (OAuth 2.0), the tool asks for permission to upload videos to, and manage captions, thumbnails and comments on, the signed-in user’s own YouTube channel. The scopes are youtube.upload and youtube.force-ssl.
  • It reads only the IDs and privacy status of videos the tool itself uploaded, to avoid duplicate uploads and to know when a video has been published.
  • It does not read subscriber lists, analytics, other channels’ data, or any other user’s data.

What the tool stores, and where

  • An OAuth access/refresh token, stored only on the user’s own computer (%APPDATA%\HiddenWonders\token.json).
  • A local log of uploaded video IDs, upload times and scheduled publish times (uploads.json on the same computer).

Nothing is stored on any server operated by the tool. The tool has no server, no analytics, no cookies and no advertising.

Sharing

No data accessed through YouTube API Services is shared with, sold to, or disclosed to any third party. Data is sent only to Google/YouTube, as part of the upload itself.

Deleting data and revoking access

  • Revoke access at any time from your Google Account security settings: https://myaccount.google.com/permissions (remove “Hidden Wonders Uploader”).
  • Delete local data by deleting the HiddenWonders folder in %APPDATA% and the uploads.json file. Once access is revoked, the stored token stops working.
  • Retention: stored data is kept only while the tool is in use. Locally stored API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
